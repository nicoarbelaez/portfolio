Proyecto personal, activo desde octubre de 2026. Es de código abierto y lo mantengo solo.

## El problema

Quien usa Claude Code con más de una cuenta (por ejemplo personal y de trabajo, o dos con límites de uso separados) tiene que cerrar sesión e iniciar otra, y pierde el contexto de lo que estaba haciendo. Cuando una cuenta llega a su límite, el trabajo se frena.

## Qué construí

`cid` es un binario en Go que guarda cada cuenta en el llavero del sistema (Windows Credential Manager, macOS Keychain o Linux Secret Service) y cambia entre ellas dentro de una sesión de Claude Code en marcha. Incluye:

- Un plugin de Claude Code con el comando `/account`, que responde al instante sin gastar un turno del modelo.
- Barras de uso por cuenta, para las ventanas de 5 horas y semanal.
- Cambio automático entre una cuenta principal y una de reserva cuando se acerca el límite.
- Actualización propia del binario y del plugin, con verificación de checksum.
- Salida en inglés y español.
