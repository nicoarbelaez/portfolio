Personal project, active since October 2026. It is open source and I maintain it alone.

## The problem

Anyone using Claude Code with more than one account (say personal and work, or two with separate usage limits) has to log out and log in again, and loses the context of what they were doing. When an account hits its limit, the work stalls.

## What I built

`cid` is a Go binary that stores each account in the OS keyring (Windows Credential Manager, macOS Keychain or Linux Secret Service) and switches between them inside a running Claude Code session. It includes:

- A Claude Code plugin with an `/account` command that answers instantly without spending a model turn.
- Per-account usage bars for the 5-hour and weekly windows.
- Automatic switching between a principal and a reserve account as the limit approaches.
- Self-update for the binary and the plugin, with checksum verification.
- English and Spanish output.
