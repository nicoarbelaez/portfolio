## The problem

The dollar, public contracts, competitors, news and regulation live in different sources. They rarely explain what a change means for a specific company, and checking them by hand every day does not scale.

## What I built

Smart Work Core started as a university commission for a client who prefers to stay anonymous. Jorge Velásquez created the initial repository. I designed and built the product, including the Next.js application.

- **Alert radar.** Each signal has a severity (informative, watch or alert), the rule that produced it and a link to the original source. It can be marked new, reviewed or dismissed.
- **Rule engine.** Pure TypeScript functions that check the daily TRM (the official COP/USD rate) move, contracts about to expire, new competitor contracts, the energy price, and keyword mentions in news and regulation. The user adjusts the thresholds.
- **PESTEL, a decision log and a weekly briefing** that exports to Markdown and CSV.
- **Several companies**, each with its own profile, competitors and keywords. An AI-guided onboarding drafts the initial profile.
- **AI assistant** that answers about the data already loaded, using eight read-only tools.

Data comes from datos.gov.co (TRM, SECOP II contracts, Supersociedades reports), the World Bank, XM and RSS feeds from Colombian media.

## Results

- A complete application with radar, PESTEL, briefing, assistant and multi-company management.
- Access restricted by Cloudflare Access, with JWT validation inside the application itself.
- An architecture that checks itself: a test fails if the rule core depends on infrastructure.

I do not publish usage metrics: the tool has restricted access and I have no verifiable figures.
