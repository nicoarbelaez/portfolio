## Architecture

A monorepo with Turborepo and pnpm 10. The API (NestJS 11 on Fastify 5) only receives and enqueues. The heavy work runs in a separate standalone NestJS worker with 34 BullMQ queues. The dashboard is Next.js 16 and the landing page is Astro. PostgreSQL 16 with pgvector stores the business data and the semantic search over the catalog and FAQs.

## Key decisions

- **An own ReAct loop, no agent SDK.** The agent is a service in the repository on top of OpenRouter, with no OpenAI Agents SDK and no LangGraph. Guards, per-iteration token counts and budget cut-off live in the same code as the loop.
- **Multi-model routing with fallbacks.** An intent classifier (Gemini 2.5 Flash Lite) separates simple cases from those that need reasoning. The agent tier uses GLM 5.3 Flash with DeepSeek V4 Flash as fallback. Models are chosen by cost per call and latency, and structured outputs use strict JSON Schema where the model supports it.
- **One tool per domain with an `action` discriminator.** Catalog, cart, orders, payments, address, delivery, business hours, assets, cakes, handoff, memory and FAQ. The model sees a few tools with many actions, not dozens of loose functions.
- **The model does not invent numbers.** Post-LLM guards block amounts that did not come from a tool, ungrounded payment details and false handoff promises.
- **Fast acknowledgement, asynchronous work.** Kommo disables webhooks if more than 100 responses in 2 hours take longer than 2 s. So the API only validates, logs and enqueues, and the rest runs in queues with a per-conversation buffer and lock to avoid answering twice.
- **Cost and loop control.** A per-business AI budget with cut-off, a cap on messages per conversation, and spend reconciliation against OpenRouter. The cap was tightened after an incident in which the agent talked to an autoresponder; the postmortem is in `docs/incidentes.md`.

## Testing, CI and deployment

- Jest 30 in the API and Vitest 3 in the dashboard, plus e2e tests and tests against a real PostgreSQL for cash concurrency and row locking.
- GitHub Actions with a self-hosted runner on the VPS: typecheck, lint and tests; migrations from scratch on pgvector; schema drift diff; a destructive-migration gate and four production Docker builds.
- Deployment verifies, migrates production and publishes the API, worker and dashboard through the Dokploy API on Docker Swarm with Traefik. There are about 140 Prisma migrations since June 2026.
- The repository is private, so there is no code link.
