## Architecture

Mecateo is a monorepo (pnpm 10 and Turborepo) with several deployable apps and several shared packages. The hot path, an NFC stand tap, runs in a separate Go service so redirection does not depend on the API. Everything else (administration, orders, payments, audit) lives in NestJS 11 on Fastify 5, with PostgreSQL 16 and Prisma 7.

## Data flow

A tap goes through the redirector, which answers first and records after. A stand purchase takes another path: the payment gateway notifies by webhook and a worker reconciles whatever did not arrive.

## Key decisions

- **A Go redirector, separate from the API.** Every tap is a public request that must answer fast even when the API is busy. The service only resolves the code, redirects and queues the event.
- **Privacy by design in analytics.** The visitor is identified by `SHA256(daily salt, link, IP, user agent)`. Neither the IP nor the user agent is stored, and the salt rotates daily, so a person cannot be followed across days.
- **Transactional outbox.** Domain events are written in the same transaction as the change (`platform.outbox_event`) and a worker dispatches them. An event is not lost if the process dies between the commit and the queue. The administrative audit trail is also written in the same transaction.
- **Payments behind a port.** Wompi plugs in through an adapter. Webhooks are deduplicated, a reconciliation worker retries with backoff, and orders follow a state machine. Shipping policies are versioned with copy-on-write, and consent goes into an insert-only table.
- **A white-box AI gateway.** It forwards to OpenRouter without altering the request. Before each call it reserves credits and settles afterwards, in an insert-only ledger. There is a per-request and a daily spend cap, per-organization blocking and a global kill switch. Content is audited encrypted with AES-256-GCM and 30-day retention, and staff reads are logged.
- **Multi-tenant by organization and branch.** Better Auth handles organizations, roles (owner, admin, member), API keys with rotation and expiry, and 2FA for staff. Cloudflare Access protects administration.

## Testing, CI and deployment

- Vitest as the runner. The admin API has more than 1,500 tests, and the repository keeps its requirements with the evidence path and the test name.
- GitHub Actions with self-hosted runners on the VPS. The pipeline checks for destructive migrations, runs a smoke contract and deploys through Dokploy. There is a staging environment.
- Each app ships as a Docker image behind Traefik. ADRs and runbooks (backups, migrations, gateway deployment) live in `docs/`.
- The repository is private, so there is no code link.
